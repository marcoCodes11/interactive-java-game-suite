# interactive-java-game-suite
Interactive Java Game Suite is a desktop application developed using Java and Java Swing that combines four interactive games within a centralized graphical interface: 8-Puzzle, 15-Puzzle, Tic-Tac-Toe, and a Card Matching Game.

The application uses object-oriented and event-driven programming to manage game logic and user interactions. Features include randomized puzzle and card generation, move validation, game-state tracking, win and draw detection, player turn management, timers, attempt tracking, and automatic game resets.

Features
Centralized GUI for launching four different games
Interactive 8-Puzzle and 15-Puzzle games
Two-player Tic-Tac-Toe with custom player names
Card matching game with randomized cards, timer, and attempt tracking
Move validation and win/draw detection
Real-time game-state and GUI updates
Restart and reset functionality
Event-driven controls using Java Swing and ActionListeners
Technologies

Java • Java Swing • Object-Oriented Programming • Event-Driven Programming • NetBeans
